# Netflix Data Visualization – Power BI

## Objective
The objective of this task is to create meaningful data visualizations and tell a story using Netflix data.

## Dataset
- cleaned_netflix_data.csv

## Tools Used
- Microsoft Power BI

## Visualizations Created
1. Movie vs TV Show distribution  
   - Shows that Movies dominate Netflix content.

2. Content growth by release year  
   - Highlights how Netflix content has increased over the years.

3. Country-wise content distribution  
   - Identifies top countries contributing to Netflix’s content library.

## Key Insights
- Movies are more prevalent than TV shows on Netflix.
- Netflix content production has grown significantly in recent years.
- A few countries contribute the majority of Netflix titles.

## Conclusion
This project demonstrates how data visualization can be used to derive insights and present data in a clear and engaging manner.
